# Интеграционное тестирование: mathjax.cr vs MathJax (1-в-1)

**Датасет:** 1000 уникальных TeX-формул из англоязычной Википедии
(`tools/fetch_formulas.cr`, CirrusSearch `insource:/\<math\>/`, ~700 статей,
всего найдено ~19 000 уникальных формул, взяты первые 1000).

**Эталон:** `tools/make_reference.js` — настоящий MathJax (`mathjax-full`,
TeX-вход со всеми пакетами кроме `bussproofs`, `SerializedMmlVisitor`).
Одни и те же формулы подаются обоим парсерам.

**Сравнение:** `tools/compare.cr` — нормализация обоих MathML-деревьев
(сглаживание inferred-`mrow`/пустых `mstyle`, whitelist семантических
атрибутов: mathvariant, linethickness, columnalign, width, minsize/maxsize,
mathcolor…; `data-mjx-*` отбрасываются) и структурное сравнение
(kind + текст токена + атрибуты).

## Результаты (фиксация)

| Метрика | Значение |
|---|---|
| Формул всего | 1000 |
| Разобрано mathjax.cr | **993 (99.3%)** |
| Comparable (MathJax разобрал без noundefined-подделок) | 999 |

Прогресс по итерациям (фиксы по diffs): 42.5% → 55.1% → 72.9% → 85.1% →
90.1% → 92.2% → 95.2% → 96.1% → 97.3% → 97.8% → 98.7% → 99.1%.

## Наши 7 ошибок разбора

- 5× wiki-приватные макросы `\R`, `\Z`, `\Q`, `\Complex` — определены в
  прелюдии Википедии; MathJax тоже не знает их (пакет `noundefined`
  подменяет красным текстом — эти формулы исключены из comparable);
- 1× `\left` без распознаваемого разделителя.

## 2 известных структурных отличия

- `\left( ... \\ ... \right)`, разорванный между строками `align` —
  MathJax тащит группу через разрыв строки, мы — нет ([777], [803]).

## Поведенческие находки, найденные датасетом

- `-` → минус U+2212, `*` → `∗`, `~` → `mtext` nbsp, `\ ` → `mtext` nbsp;
- `\sum` даёт `munderover` даже в инлайн-режиме (movablelimits);
  `\int`-семейство — обычные скрипты;
- невидимый оператор применения функции U+2061 после `\sin`/`\cos`/...,
  но идущий ПОСЛЕ скриптов (`\cos^2`); `\gcd`/`\det`/`\Pr`/`\lim` — `mo`
  без U+2061;
- `\mathrm` склеивает буквенные ранги в один `mi` (`onions`), `\rm` — нет;
  шрифтовые варианты касаются только латиницы (и греческого для
  sans-serif), `\mathit` красит и скобки; цифры жирнеют только от `\bf`;
- `\big/\Big/\bigg/\Bigg` = 1.2/1.623/2.047/2.47em; заборы `\binom` —
  2.047em (1.2em внутри дробей/`\textstyle`);
- числа: `\d+(\.\d*)?` с хвостовой точкой (`130.`) и `{,}` внутри
  (`10{,}000` → один `mn`);
- `\dots` контекстен: `⋯` перед `+ -=<>`, иначе `…`;
- повторы `\uparrow` склеиваются в один `mo` (`↑↑`, `↑↑↑`);
- `:=` — один оператор; `\not\in` → `∉` (merge);
- align: пустой `mi` в нечётных ячейках (левый операнд), `columnalign`
  right/left; cases закрывается пустым fence-`mo` и имеет
  `columnalign` по числу колонок; вложенные матрицы получают
  `columnalign="center"`;
- `\cfrac`: `mpadded width=0` перед каждым аргументом;
- палитра имён цветов расширения color (Cyan → #00AEEF и т.д.);
- заглавные греческие, `\infty/\nabla/\emptyset/\aleph` — upright
  (`mathvariant="normal"`), но не `\beth` и не `\partial`.
